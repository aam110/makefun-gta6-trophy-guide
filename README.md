**Leonida Legend** is an offline GTA VI trophy guide + tracker, built for the [make.fun](https://make.fun) **gta6-trophy-guide-01 — Build the best GTA 6 trophy guide** competition. It runs entirely offline from static files: no network request, no build step.

## The guide

All **55 official trophies** — 1 platinum, 2 gold, 6 silver, 46 bronze — each with an original step-by-step guide, kind (story, activities, collectibles), missable flag, roadmap stage, and named sources beside every guide. Seven trophies with no confirmed method are explicitly marked as predictions.

- **Roadmap to platinum** — 3 stages, ~200 hours, one playthrough, with live per-stage progress.
- **Tracker** — localStorage checklist, export/import JSON, search, grade and kind filters, spoiler toggle.
- **1 missable flagged** — Positive Mental Attitude, with the no-mission-replay save warning.

## Run it

Open `app/index.html`, or serve the folder (`npx serve app`). `main.ts` builds the offline dossier (`dossier.json`) the same way twice, byte for byte.
